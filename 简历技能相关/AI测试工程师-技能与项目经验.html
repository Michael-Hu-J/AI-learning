AI TEST ENGINEER · SKILL MAP

AI测试工程师核心能力图谱

融合传统质量保障与 AI 工程化实践，覆盖从需求分析、智能用例生成到模型评测与上线监控的全链路测试能力。

AI AI 提效与 Vibe Coding

  • 深度使用 Cursor、Claude Code、VS Code 等 AI 编程工具，以自然语言驱动测试脚本与工具开发
  • 践行 Vibe Coding 工作流：描述意图 → AI 生成 → 人工校验 → 迭代优化，显著缩短脚本编写周期

QA 智能测试用例生成

  • 基于 Skills + 大模型（testcase-skills 生成/评审），从需求文档一键生成结构化、可评审的测试用例
  • 内置 AI 自动评审能力，覆盖完整性、边界值、异常路径等维度
  • 支持 PRD / 用户故事 / API 文档等多源输入，输出可直接导入测试管理平台

API 接口自动化测试

  • 构建 API 自动化 Agent：文档或自然语言 → Pytest 脚本 → 自动执行 → 日志归档 → 报告导出
  • 实现"一句话完成接口测试"：描述测试意图即可生成含断言、参数化、Fixture 的完整用例
  • 技术栈：FastAPI、Pytest、MySQL、Redis，支持 CI/CD 流水线集成

UI UI 自动化测试

  • Skills + Playwright 深度集成（UI-skills 规划/执行/自愈）：自然语言描述 → 脚本生成 → 智能自愈 → 一键回放
  • 支持 Web 端高可维护性自动化闭环，降低元素变更导致的脚本维护成本
  • 结合 AI 视觉识别辅助定位，提升复杂动态页面的测试稳定性

PERF 性能测试

  • 基于 load-testing Skills（k6 / JMeter / Locust），覆盖传统后端与 AI 推理服务两类压测场景
  • 针对 AI 应用关注 Token 吞吐、首 Token 延迟、流式响应 P95 等专属指标
  • 自研监控脚本采集 QPS、响应时间分布、并发稳定性，输出可视化压测报告

DATA 智能造数与业务测试

  • 基于 Skills 数据工厂（data-factory / testcase-data-generator），自然语言指令生成符合业务规则的复杂测试数据
  • 缺陷闭环 Skills（bug-reporter / defect-analysis）：pytest 失败自动生成缺陷草稿，标准化复现步骤与严重级别
  • 缺陷同步与进度报告（defect-sync / progress-reporter）：一键推送禅道/云效，输出通过率与会话统计报告
质量保障闭环：需求建模与测试方案（testplan-skills / requirement-modeling）→ Skills 驱动用例生成与自动化执行 → CI 门禁准出（ci-gate）→ 基座模型评测 / RAG 效果验证 / Agent 行为测试 → 上线监控告警，提供 AI 应用端到端 QA 能力。

TECHNICAL DEPTH · LLM & EVALUATION

技术深度：大模型评测与 AI 架构理解

系统掌握 LLM、RAG、Agent、Skills 等核心概念，具备量化评测与持续优化能力。

大模型与 AI 架构认知

LLM 大语言模型

理解 Transformer 架构、Prompt 设计、上下文窗口限制；熟悉主流开源/闭源模型特性与选型策略。

RAG 检索增强生成

深入 RAG 架构与调优策略：分块策略、Embedding 选型、重排序、召回率与幻觉控制。

AGT Agent 与 Skills

理解 Agent 规划、工具调用、多轮对话机制；熟悉 Skills 体系、MCP 协议及 Agent 编排框架。

评测框架与量化实践

评测框架体系

  • 系统掌握 OpenCompass、RAGAS、AgentBench 等评测框架的核心维度与指标体系
  • 对接真实 API 对主流开源模型进行多维度横向评测，输出可视化对比报告
  • 结合业务场景搭建可复用评测基准集，持续追踪模型版本迭代与选型效果

RAG 效果诊断与优化

  • 基于 RAGAS 框架进行 Faithfulness、Answer Relevancy 等指标量化，定位检索与生成链路短板
  • 结合评测结果指导分块粒度、Top-K、Prompt 模板等参数调优
  • 了解 LLM 微调基本原理，能根据评测数据推动模型侧优化决策

专项评测能力

  • NL2SQL 设计语义测试题库，实现语义相似度评分算法，验证模型 SQL 生成与理解能力
  • LLM-as-Judge 搭建自动化评分流水线，保障多轮评测的稳定性与一致性
  • 安全评测 设计红队用例集，覆盖 Prompt 注入、越狱、偏见、幻觉、合规等，识别潜在安全风险

性能与稳定性

  • 自研 LLM 服务压测监控脚本，验证高并发场景下的吞吐能力与响应稳定性
  • 建立 Token 消耗、超时率、错误码分布等 AI 应用专属监控指标
  • 区分推理延迟与端到端延迟，制定分层 SLA 与告警阈值

MANAGEMENT PRACTICE

管理实践 · 测试团队管理与质量保障

负责测试团队项目管理、质量把控、流程落地与团队建设，推动高质量按期交付。

1

项目管理

主导组内双周需求评审与排期，拆解测试任务并合理分配资源；推进跨部门（产品/开发/运维）协作，主动识别并清除项目阻塞点，保障大促/核心版本高质量按期交付。

2

质量把控

建立测试准入准出标准（门禁），全周期跟踪项目风险；严控提测质量与上线审批，核心业务全年零重大事故。

3

流程落地

负责 Jenkins 环境部署与提测分支校验；规范提测单、上线操作单及 Wiki 记录等过程资产，实现研发流程标准化、可追溯。

4

自动化建设

担任接口自动化负责人，主导核心业务场景脚本编写与维护；优化流水线报错预警机制，降低误报率，回归测试效率提升 50%。

5

质量运营

定期组织月度质量复盘会，针对线上遗留问题进行根因分析，沉淀避坑指南与案例库，有效降低同类问题复发率。

6

应急保障

建立 7×24 小时线上响应机制，快速定位并推动 Bug 修复，推动 MTTR（平均恢复时间）缩短 30%，保障业务连续性。

7

团队建设

实行「导师制」带教新人与业务分享机制，制定新人培养计划；负责团队成员绩效考评与 1 对 1 反馈，提升团队整体战斗力。
