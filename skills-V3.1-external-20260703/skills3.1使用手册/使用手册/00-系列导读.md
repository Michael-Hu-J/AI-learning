## 买包后最常问的三句话

1. **「我不会写 Python，能不能用？」** —— 能。声明式 spec + `./generate.sh` 不必手写 Python。  
2. **「和网页版 GPT 写脚本有啥区别？」** —— 流程固定在 SKILL 里、产出格式统一、本地 generate 可进 CI。  
3. **「是不是必须一直开着 AI？」** —— 不是。不开 AI 也能 generate + pytest。

## Day 1：解压后 30 分钟清单

按顺序打勾即可（细节见 `02-三分钟跑通.md`）：

- [ ] **解压**到本机，进入含 `generate.sh` 的根目录（目录名一般为 `skills-专业版V3.0`）  
- [ ] **Python 3.8+**：`python3 --version`  
- [ ] **最小依赖**：`python3 -m pip install pytest requests PyYAML`  
- [ ] **可执行权限**（Linux/macOS 一次即可）：`chmod +x generate.sh`  
- [ ] **生成**：`./generate.sh templates/api_smoke.md`（Windows 用 `bash generate.sh ...`）  
- [ ] **验收（无后端）**：`cd output && python3 -m pytest api_smoke.py --collect-only -q` → 应看到 `N tests collected`（无报错即可；条数随模板扩展，以终端为准）  
- [ ] **终端无字时**：`cat output/.last_run_message.txt`  
- [ ] **（可选）开 AI 编辑器**：推荐 Cursor（免费，https://cursor.sh）或 Windsurf（免费，https://windsurf.com）
  - 安装后：File → Open Folder → 选包根目录
  - 试一次 `@testcase-skills/生成/SKILL.md`（见 `04`）
  - **不用 AI 编辑器也能用**！所有功能都有命令行替代方案  
- [ ] **（可选）全绿**：配置 `TEST_BASE_URL` 指向你们服务或演示后端后再 `pytest -v`

没有演示后端也能完成上面带「无后端」的步骤；演示系统（进销存）**联系交付方获取**，详见 `14-FAQ`。
