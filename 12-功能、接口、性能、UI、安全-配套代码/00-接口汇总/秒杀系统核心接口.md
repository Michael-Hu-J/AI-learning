# 秒杀系统核心接口清单

> 对应实战系统 `seckill_finance_system/app.py`，默认地址 `http://localhost:5001`

## 认证模块

| 方法 | 路径 | 说明 | 请求体示例 |
|------|------|------|-----------|
| POST | `/api/auth/login` | 登录，返回 JWT Token | `{"username":"admin","password":"admin123"}` |
| POST | `/api/auth/register` | 用户注册 | `{"username":"test1","password":"test123"}` |

**登录成功响应：**
```json
{
  "message": "登录成功",
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "user": {"id": 1, "username": "admin", "role": "admin"}
}
```

**Header（需登录的接口）：**
```
Authorization: Bearer <token>
Content-Type: application/json
```

## 商品模块

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/products` | 商品列表（分页） | 公开 |
| POST | `/api/products` | 创建商品 | admin |
| PUT | `/api/products/{id}` | 修改商品 | admin |
| DELETE | `/api/products/{id}` | 删除商品 | admin |

**创建商品请求体：**
```json
{"name": "测试手机", "price": 2999.00}
```

---

## 抢购/秒杀模块

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/seckill/list` | 抢购活动列表 | 公开 |
| POST | `/api/seckill/activities` | 创建抢购活动 | admin |
| POST | `/api/seckill/order` | 抢购下单 | 需登录 |

**抢购下单请求体：**
```json
{"productId": 1}
```

**成功响应：**
```json
{
  "success": true,
  "order_id": 1,
  "order_no": "SK20240101120000ABCD1234",
  "message": "抢购成功"
}
```

**常见错误：**
| 状态码 | error 信息 | 原因 |
|--------|-----------|------|
| 400 | 您已参与过该商品的抢购活动 | 重复下单（Redis 去重） |
| 400 | 库存不足 | 库存为 0 |
| 401 | 未授权，请先登录 | 未带 Token |
| 400 | Redis服务未启动，抢购功能不可用 | Redis 未启动 |

## Postman 快速串联（4 步）

```
1. POST /api/auth/login          → 拿 token
2. GET  /api/seckill/list        → 拿 product_id
3. GET  /api/products            → 确认商品存在
4. POST /api/seckill/order       → 带 Authorization 下单
```

---

## curl 示例

```bash
# 登录
curl -X POST http://localhost:5001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 查抢购列表
curl http://localhost:5001/api/seckill/list

# 抢购下单（替换 YOUR_TOKEN）
curl -X POST http://localhost:5001/api/seckill/order \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"productId": 1}'
```
