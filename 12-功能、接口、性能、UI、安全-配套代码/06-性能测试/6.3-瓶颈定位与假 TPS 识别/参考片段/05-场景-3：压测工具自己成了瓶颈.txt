压测发现问题
  │
  ├── TPS 上不去
  │     ├── 看 CPU → CPU 高 → 代码问题（循环/计算）
  │     ├── 看内存 → 内存高 → 内存泄漏/大对象
  │     ├── 看数据库 → 数据库 CPU 高 → SQL 慢/缺索引
  │     ├── 看网络 → 网络带宽满 → 大文件传输
  │     └── 看连接池 → 连接池满 → 加大连接池
  │
  ├── 响应时间慢
  │     ├── 看 SQL → SQL 慢 → 加索引/优化查询
  │     ├── 看缓存 → 没走缓存 → 加缓存/调缓存策略
  │     ├── 看外部调用 → 第三方接口慢 → 加超时/异步化
  │     └── 看锁 → 锁竞争 → 减少锁范围/改用无锁结构
  │
  └── 错误率高
        ├── 看错误类型
        │     ├── Connection refused → 服务挂了/端口满了
        │     ├── Timeout → 超时配置太短/系统太慢
        │     ├── 500 → 代码 bug
        │     └── 429 → 限流了
        └── 看日志 → 定位具体原因
