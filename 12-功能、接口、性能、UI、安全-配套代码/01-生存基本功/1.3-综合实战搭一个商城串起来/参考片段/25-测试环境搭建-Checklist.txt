□ 1. 确认依赖服务都启动了
  → MySQL、Redis、消息队列...
  → docker ps 看容器状态

□ 2. 确认数据库版本跟生产一致
  → mysql --version
  → 版本不一致可能导致 SQL 语法报错

□ 3. 确认配置文件正确
  → 数据库连接串、Redis 地址、端口号
  → 测试环境用测试配置，别搞混

□ 4. 初始化基础数据
  → 执行 tests/fixtures/ 下的 SQL 脚本
  → 城市列表、商品分类、权限角色

□ 5. 造测试数据
  → 用数据工厂或 SQL 脚本
  → 覆盖正常、异常、边界场景

□ 6. 跑健康检查
  → ./health_check.sh
  → 数据库能连、接口能调、日志能写

□ 7. 记录环境信息
  → 把环境信息写到测试报告里
  → 数据库版本、中间件版本、应用版本
