接口名称：创建订单
请求方式：POST
接口路径：/api/v1/order/create

请求参数：
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | int | 是 | 用户ID |
| items | array | 是 | 商品列表 |
| addressId | int | 是 | 地址ID |

响应示例：
{
    "code": 0,
    "data": {
        "orderId": 12345,
        "status": "created"
    },
    "message": "success"
}

错误码：
| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 用户不存在 |
| 1003 | 库存不足 |
