# 缺陷报告字段自检

## 发布前勾选

- [ ] 标题含 **模块 + 现象**（非「系统有问题」）
- [ ] 严重程度有依据（对照 severity_guide）
- [ ] 发现方式、关联用例/nodeid 已填
- [ ] 问题描述含 **期望 vs 实际**
- [ ] 失败摘要 ≤30 行，保留 AssertionError 关键行
- [ ] 状态为 **Draft**
- [ ] 未编造截图、未声称已联系开发

## 常见翻车

| 现象 | 改法 |
|------|------|
| 整段 pytest 输出粘贴 | 改为失败摘要 + nodeid |
| 环境错误标 Critical | 改 High/Medium + 环境疑似 |
| 缺复现步骤 | 从 nodeid 反推接口/用例名写入描述 |
