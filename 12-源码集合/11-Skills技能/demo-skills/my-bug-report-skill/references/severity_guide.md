# 严重级别速查（demo 版）

| 级别 | 定义 | 典型 |
|------|------|------|
| Critical | 核心不可用、数据丢失 | 支付全挂、生产库不可写 |
| High | 主流程不通 | 登录接口 500（服务已启动且非环境问题） |
| Medium | 次要功能异常 | 错误提示文案不对 |
| Low | 体验细节 | 错别字 |

## 环境 vs 产品（草稿阶段）

| 信号 | 建议分流 |
|------|----------|
| `Can't connect to MySQL` / `Connection refused` | **环境疑似**，标题注明「待确认环境」 |
| `assert 500 == 201` 且 body 含业务 error | **产品待确认** |
| `404` 对不存在的资源 | 可能是 **预期行为**，核对用例 |

## 缺陷类型

功能 / 界面 / 性能 / 安全 / 兼容 / 数据
