# 秒杀系统测试需求（示例）

## 业务背景

电商平台限时秒杀：100 件商品，1000 并发用户抢购。

## 核心接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/seckill/products/{id}` | GET | 查询秒杀商品 |
| `/api/seckill/order` | POST | 提交秒杀订单 |
| `/api/seckill/stock/{id}` | GET | 查询库存 |

## 测试关注点

- P0：库存扣减正确、超卖防护、重复下单
- P1：接口响应时间、限流降级
- P2：异常参数、未登录用户
