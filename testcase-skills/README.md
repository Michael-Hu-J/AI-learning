# AI 测试用例设计技能包（免费版）

> 规划 · 分析 · 生成 · 评审 · 8 维覆盖矩阵  
> 在 Cursor / Windsurf / VS Code 里打开本文件夹，复制下面话术即可使用

---

## 第一步：怎么打开

1. 解压本文件夹 `testcase-skills`
2. 用 **Cursor** 或 **Windsurf** 打开这个文件夹（作为工作区根目录）
3. 打开 AI Chat，把下面话术复制进去

不需要安装 Python、不需要配环境。本包是一组 **Skill 说明文档**，AI 读取后会按规则帮你写用例。

---

## 第二步：最常用——直接从 PRD 生成用例

把 `@你的需求文档.md` 换成你真实的 PRD 文件路径。

```text
@生成/SKILL.md
@你的需求文档.md

请按 8 维矩阵生成测试用例，保持 PRD 章节结构，输出到 output/模块名_testcases.md
```

**8 维矩阵是什么？**

| 维度 | 含义   | 举例         |
| -- | ---- | ---------- |
| N  | 正常流程 | 正确账号密码登录成功 |
| B  | 边界值  | 密码最短/最长长度  |
| T  | 类型校验 | 字段类型传错     |
| E  | 异常场景 | 服务 500、超时  |
| A  | 权限   | 未登录访问受保护接口 |
| D  | 依赖   | 先登录再下单     |
| I  | 幂等   | 重复提交只成功一次  |
| S  | 安全   | SQL 注入、XSS |

## 第三步：按场景选 Skill

| 你想做什么          | 引用哪个 Skill     | 复制话术                            |
| -------------- | -------------- | ------------------------------- |
| **直接出用例**（最常用） | `生成/SKILL.md`  | 见上方「第二步」                        |
| 需求很粗，先定范围      | `规划/SKILL.md`  | `@规划/SKILL.md` + 描述本轮要测什么       |
| 需求复杂，先拆场景      | `分析/SKILL.md`  | `@分析/SKILL.md` + PRD，输出场景/边界/规则 |
| 用例写完了，上线前检查    | `评审/SKILL.md`  | `@评审/SKILL.md` + 你的用例文档         |
| 公司有需求库，想先对齐文档  | `00_知识增强约定.md` | 先读这篇，再走进度流水线                    |

### 推荐流水线（复杂需求）

```text
# 1. 分析
@分析/SKILL.md
@需求文档.md

# 2. 生成（新开一轮 Chat 或接着上文）
@生成/SKILL.md
请基于上面的分析结果生成完整测试点

# 3. 评审（可选）
@评审/SKILL.md
@output/xxx_testcases.md
```

## 引用路径说明（重要）

**本文件夹已是工作区根目录时**（推荐），Chat 里这样写：

```text
@生成/SKILL.md
```

## 输出长什么样

生成结果一般是 Markdown，包含：

- 与 PRD 对齐的章节结构
- 可判定 PASS/FAIL 的测试点（不是「系统应支持 XX」这种空话）
- 文末「通用覆盖矩阵自检」和「待澄清清单」

详细格式见 `生成/references/delivery_standard.md`（AI 会自动遵守）。

## 常见问题

**Q：没有 PRD，只有一句话需求可以吗？**  
可以。先 `@分析/SKILL.md`，把一句话需求贴进去，再 `@生成/SKILL.md`。

**Q：必须走规划 → 分析 → 生成 → 评审 四步吗？**  
不必须。PRD 写得清楚时，只用 `生成/SKILL.md` 就够。

**Q：文档里的「秒杀财务系统」是什么？**  
虚构演示项目，用来举例。你换成自己的业务和 PRD 即可。

**Q：生成后怎么执行自动化？**  
本免费包只做到**用例设计**。接口/UI 自动化在完整版（api-skills、UI-skills 等）。
