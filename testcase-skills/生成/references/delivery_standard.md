# 交付标准

> 示例项目：**秒杀财务系统**；样例文档见 `templates/测试用例-需求文档.md`、`examples/output_seckill_auth_testcases.md`。

对外交付或入库前，测试用例文档须符合本标准（与 `templates/测试用例-需求文档.md` 可对齐）。

---

## 1. 文档头（必填）

```markdown
# [模块名] 测试用例

## 文档信息
- 依据需求：[文件名/版本/链接]
- 生成版本：规则 1.2.0（skills-专业版V2.0 · testcase-skills/生成）
- 测试范围：[一句话]
- 结构说明：[2/3/4 级层级]
- 待澄清汇总：[条数，或「无」]
```

---

## 2. 用例编号（专业版必填）

| 前缀 | 含义 | 示例 |
|------|------|------|
| F- | 核心流程 | F-01 |
| L- | 列表/查询 | L-01 |
| D- | 详情/单条读 | D-01 |
| C- | 创建/新增 | C-01 |
| U- | 更新/编辑 | U-01 |
| X- | 删除/作废 | X-01 |
| V- | 校验/边界 | V-01 |
| P- | 权限/安全 | P-01 |
| N- | 非功能 | N-01 |
| T- | 待澄清占位 | T-01 |

格式：`{前缀}-{两位序号}`，在检查点标题或评审表中出现。

---

## 3. 优先级

| 级别 | 定义 | 建议占比 |
|------|------|----------|
| P0 | 核心流程、资金/权限、数据丢失风险 | ≤20% |
| P1 | 主功能正向与关键异常 | ~40% |
| P2 | 边界、次要场景 | ~30% |
| P3 | 低概率、体验类 | ≤10% |

每条 **评审表** 行须带优先级；Markdown 检查点可在 `####` 后注释 `<!-- P0 -->` 或单独附评审表章节。

---

## 4. 推荐文档结构

```markdown
## 文档信息
## 需求追溯表（专业版）
## 核心流程测试
## 详细功能点测试
## 用例评审表（专业版，表格）
## 通用覆盖矩阵自检（专业版）
## 待澄清清单（专业版）
```

### 4.1 需求追溯表

| 需求段落/标题 | 用例编号范围 | 覆盖说明 |
|---------------|--------------|----------|

### 4.2 用例评审表（简表）

| 编号 | 名称 | 优先级 | 类型 | 标签 |
|------|------|--------|------|------|
| L-01 | … | P0 | functional | module,list |

类型建议：`smoke_sanity` | `functional` | `regression` | `boundary` | `security` | `integration` | `pending_clarification`

## 5. 检查点正文规范

- 测试点句式见 `checkpoint_format.md`
- 禁止仅复述 PRD；见 `test_point_validation.md`
- 待澄清须写清 **要问产品什么**

---

## 6. 可选：JSON 入库结构

与测试平台对接时，每条用例可导出为：

```json
{
  "case_id": "L-01",
  "name": "在售列表仅含在售商品",
  "priority": "P0",
  "type": "regression",
  "tags": ["products", "list", "status"],
  "preconditions": "库中同时在售与已下架商品",
  "test_steps": [
    {"step": "打开商品列表", "result": "仅返回在售商品 ID"}
  ],
  "requirement_ref": "浏览在售商品列表",
  "status": "active"
}
```

`test_steps` 每项仅 `step` + `result`，**不得**使用 `expected_result` 键名。

---

## 7. 专业版交付要点（本包默认）

| 项 | 要求 |
|----|------|
| Step 0～6 | 全流程执行 |
| 通用覆盖矩阵 | **全表扫，触发行必有点或待澄清** |
| 用例编号 | **必填** |
| 评审表 | **必填** |
| 矩阵自检表 | **必填** |
| 待澄清清单 | **文末汇总** |
| OpenAPI 叠加 | 有契约时 **建议必做** H 维 |
